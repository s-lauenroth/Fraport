# accordion

Custom **accordion** block. Purpose: Ruled expandable rows with a label and chevron toggle.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: Each row has a label cell and an optional id cell (anchor id); the panel content is the blocks and default content that follow in the same section.

## Supported variations

| Variation | Option class |
| --- | --- |
| Open | `open` |
| Grey | `grey` |
| Shadow | `shadow` |
