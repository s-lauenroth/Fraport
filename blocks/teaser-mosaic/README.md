# teaser-mosaic

Custom **custom** block. Purpose: Anniversary photo mosaic with an overlay teaser panel, logo and colour tiles.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per tile in reading order, first row the main tile: picture + text, picture only, empty, or video link + poster.
