# video-player

Custom **video** block. Purpose: Hosted video player with poster image and play button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row: video link (file, YouTube or Vimeo), optional poster picture, optional caption paragraphs; autoplay-background: a second picture is the overlay graphic.

## Supported variations

| Variation | Option class |
| --- | --- |
| Autoplay Background | `autoplay-background` |
