# columns-sidebar

Custom **columns** block. Purpose: Article or press release body beside a narrow sidebar with contact cards and downloads.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row, two cells: main body (headings, text, lists, tables, images) and sidebar (contact card picture + text + links, download links with file meta, further-information text); the sidebar cell may be a fragment link.
