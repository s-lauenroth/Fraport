# image-gallery-tiles

Custom **custom** block. Purpose: Grid of zoomable 16:9 image tiles opening a lightbox slider.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: One cell per image: a picture paragraph and a heading used as the image title.
