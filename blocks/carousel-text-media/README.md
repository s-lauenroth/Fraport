# carousel-text-media

Custom **carousel** block. Purpose: One-at-a-time slider of text plus media slides (quotes with portraits, history entries, vehicles).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per slide: a media cell with a picture and a text cell (heading, quote, paragraphs, links); a first heading-only row is the title.

## Supported variations

| Variation | Option class |
| --- | --- |
| Full Width Photo | `full-width-photo` |
| Alt | `alt` |
| Image Right | `image-right` |
| Image Right 2 | `image-right-2` |
