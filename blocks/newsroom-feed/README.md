# newsroom-feed

Custom **custom** block. Purpose: Shadowed panel listing dated headline links with CTA buttons.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: A heading row for the title, then item rows with date, time and a headline link paragraph, then a row of CTA link paragraphs.
