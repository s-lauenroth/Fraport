# text-media

Custom **columns** block. Purpose: Rich-text content with an optional image or gradient highlight box.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional media cell (picture or short statement), then a text cell with headings, paragraphs, lists and optional CTA links.
