# related-content

Custom **carousel** block. Purpose: Paged rail of related-page teasers at the foot of a page.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per slide: optional picture, theme paragraph, linked heading, text paragraph and a Lesen CTA paragraph; two headings in one row stack two text-only teasers.
