# news-list

Custom **custom** block. Purpose: Newsroom search results page with search band, type tabs, tag filter and result rows.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: Rows classified by content: an h1 title row, a type tab list, a tag filter list, a result count paragraph, result rows (meta and date paragraphs, linked heading, teaser, picture), a load-more label and empty/error heading rows.
