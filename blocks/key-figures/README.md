# key-figures

Custom **custom** block. Purpose: Highlighted key numbers with captions that count up on scroll.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per figure: value cell as displayed, then caption cell; text variant adds a first one-cell row with heading and copy.

## Supported variations

| Variation | Option class |
| --- | --- |
| Stock | `stock` |
| Text | `text` |
| With Text | `with-text` |
| With Text 2 | `with-text-2` |
| With Text 3 | `with-text-3` |
| With Text 4 | `with-text-4` |
| Light | `light` |
