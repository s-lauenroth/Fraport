# cards

Custom **cards** block. Purpose: Grid of square image teaser cards, each card one link.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: One cell per card: a picture paragraph, an optional date paragraph (dated), an optional theme/meta paragraph, and a heading whose link is the card target.

## Supported variations

| Variation | Option class |
| --- | --- |
| Dated | `dated` |
| Contact | `contact` |
