# teaser-slider

Custom **carousel** block. Purpose: Paged rail of teasers linking to other pages.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per slide: optional picture, theme paragraph, linked heading, optional text paragraph and optional CTA paragraph.
