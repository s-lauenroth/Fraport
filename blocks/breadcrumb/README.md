# breadcrumb

Custom **breadcrumb** block. Purpose: Breadcrumb trail showing the current page position in the site hierarchy.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one placeholder cell, or optionally a list of links whose last item is the current page.

## Supported variations

No variations.
