# embed

Custom **embed** block. Purpose: Third-party iframe players such as YouTube videos or a walls.io social wall.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row with one cell per column; a cell holding only a link becomes a player, any other cell stays rich text.
